# 7Colors 你 vs 机器人

VS Code 里的 7Colors（七色染色）对战小游戏：你与 AI 轮流选色，把相邻同色格“染色”扩张领地，结束时占格多者获胜。

## 功能

- 侧栏「7Colors」视图，提供 **简单 / 普通 / 困难** 三个难度入口，点击即开一局。
- Webview 棋盘：调色盘、悬停预览、扩张传播动画、音效开关、重开一局。
- 当前难度在棋盘顶部只读显示，难度随时可在侧栏切换。
- 每局随机布置、基地异色，保证公平开局。

## 使用

1. 在活动栏点击「7Colors」图标，打开难度树。
2. 点击任一难度按钮开始游戏（已有对局时切换难度会直接应用到当前局）。
3. 在调色盘点选颜色落子；`R` 重开，`1`–`7` 快捷选色。

## 规则简述

棋盘上每个格子有一种颜色。轮到你时选一种颜色，你的所有领地及与之相邻的同色格都会被染成该色。无法选择与对方基地相同的颜色。双方都无路可走时，按占地格数判定胜负。
